# DAW UI mockups

## Most recent direction

[`soft-pc98-earth/`](soft-pc98-earth/) is the most recent and current visual direction.

It applies the flat, low-line PC-98-inspired earth-tone system across all 18 DAW views. The folder also includes a complete contact sheet.

## Earlier explorations

[`older-explorations/`](older-explorations/) contains the earlier Apple/macOS, Renoise, Black Monolith, terminal/editor, Wayland, experimental, and PC-98 concept studies. These are retained as design history rather than the current direction.
